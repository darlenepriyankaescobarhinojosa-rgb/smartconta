# SmartConta Frontend

Dashboard SaaS para administradores SmartConta.

## Stack

- React
- React Router
- TailwindCSS
- Axios
- Recharts
- Lucide icons

## Paginas

- Login
- Dashboard
- Gastos
- Ventas
- Trabajadores
- Reportes
- Vouchers
- Configuracion

## Desarrollo

```bash
npm install
npm run dev
```
